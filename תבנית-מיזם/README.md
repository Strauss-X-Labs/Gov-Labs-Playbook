# [שם המיזם]

repo של מיזם בתוכנית Gov-Labs. נוצר מהתבנית ב-[Gov-Labs-Playbook](https://github.com/Strauss-X-Labs/Gov-Labs-Playbook).

## איפה החומר של המיזם

הכול ב-repo הזה. זה המקום היחיד שאנשים וסוכנים בודקים.

| מה | איפה |
|---|---|
| **חומר גולמי**: מצגות, מסמכי Word, סיכומי מפגש ודיונים, ראיונות, תמונות | `01-ימים/NN-<יום>/`, תיקייה לכל יום |
| **תוצרים**: פרסונה, Lean Canvas ושאר הישויות החיות | `תוצרים/`. זה מה שהסוכנים קוראים וכותבים |
| **הפלייבוק**: המתודה והסוכנים שהמיזם עובד לפיהם | `.playbook/`, עותק של הפלייבוק. מאיזו גרסה: `.playbook/SOURCE` |

## איך עובדים עם סוכן

> המדריך המלא: [המדריך למנטור לעבודה עם ה-Playbook](https://claude.ai/artifact/TDTCr53RVNnHw4VhX5XCfg).

פותחים את ה-repo הזה ב-Claude Code (או Kiro / Antigravity) ומקלידים `/run-agent <שם הסוכן>`, למשל `/run-agent פרסונה דיגיטלית`. הסוכן קורא את המפרט מ-`.playbook/` ואת החומרים מ-`01-ימים/` ו-`תוצרים/`, מתשאל את הצוות, ואחרי אישור כותב את התוצר ל-`תוצרים/`.

אין צורך בהגדרה במחשב: מי שמוריד (clone) את ה-repo מקבל גם את הפלייבוק.

## עדכון לגרסה העדכנית של הפלייבוק

מקלידים `/update-project`. הסוכן מושך את הפלייבוק העדכני מ-GitHub ומחליף את `.playbook/`. הוא גם מעדכן את קבצי התבנית שלא נערכו ידנית, מוסיף תיקיות לימים חדשים, ומציג את התוכנית לאישור לפני שהוא משנה משהו.

את `.playbook/` לא עורכים ביד, כי הוא מוחלף כולו בכל עדכון. תיקון למתודה נכנס לפלייבוק עצמו, ב-PR.

## מה יש כאן

| תיקייה | מה |
|---|---|
| `01-ימים/` | תיקייה לכל יום בתוכנית, באותם שמות כמו `01-ימים/` בפלייבוק. כל החומר של היום: מצגות, מסמכים, סיכומי מפגש, שיעורי בית והחלטות. |
| `תוצרים/` | התוצרים של המיזם, קובץ MD לכל תוצר. לצידו קבצים נלווים באותו שם: תצוגה ויזואלית (`.html`) ותמונה (`.png`). קישור השיתוף נמצא בראש ה-MD. השמות זהים לשמות ב-`02-תוצרים-וטמפלטים/` בפלייבוק, וכאן ממלאים אותם בפועל. ריק בהתחלה. |
| `.playbook/` | עותק של הפלייבוק, לקריאה בלבד. |
| `.kiro/steering/` | הגדרות הסוכן של המנטור. מצביע לפלייבוק, כי התהליך, הכללים והשפה מוגדרים שם ולא כאן. |

## מי עובד כאן

- הקבוצה, דרך המנטור.
- המנטור, עם הסוכן.

## איך התוצרים נוצרים

לכל תוצר יש הגדרה בפלייבוק (`.playbook/02-תוצרים-וטמפלטים/`): מה זה, המבנה, ואיך מייצרים. כאן נמצא רק המילוי של המיזם.
