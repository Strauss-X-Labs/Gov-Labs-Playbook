# [שם המיזם]

repo של מיזם בתוכנית Gov-Labs. נוצר מהתבנית ב-[Gov-Labs-Playbook](https://github.com/Strauss-X-Labs/Gov-Labs-Playbook).

## מה יש כאן

| תיקייה | מה |
|---|---|
| `תוצרים/` | התוצרים של המיזם, קובץ לכל תוצר. אותם שמות כמו `02-תוצרים/` בפלייבוק — כאן ממלאים אותם בפועל. ריק בהתחלה. |
| `ידע/` | חומר גולמי של המיזם: ראיונות, מחקר, מסמכים, החלטות. תיקייה לכל נושא, תאריך בשם כשרלוונטי. מחליף את Google Drive. |
| `.kiro/steering/` | הגדרות הסוכן של המנטור. מצביע חזרה לפלייבוק — התהליך, הכללים והשפה מוגדרים שם, לא כאן. |

## מי עובד כאן

- הקבוצה — דרך המנטור.
- המנטור — עם הסוכן, שרואה גם את הפלייבוק וגם את ה-repo הזה.

## איך התוצרים נוצרים

לכל תוצר יש הגדרה בפלייבוק (`02-תוצרים/`) — מה זה, המבנה, איך מייצרים. כאן נמצא רק המילוי של המיזם.
