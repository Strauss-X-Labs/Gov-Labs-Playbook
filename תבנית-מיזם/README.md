# [שם המיזם]

repo של מיזם בתוכנית Gov-Labs. נוצר מהתבנית ב-[Gov-Labs-Playbook](https://github.com/Strauss-X-Labs/Gov-Labs-Playbook).

## איפה החומר של המיזם

> נקבע ע"י המנטור ב-onboarding, פעם אחת למיזם. משנים? מעדכנים **כאן** — זה המקום היחיד שאנשים וסוכנים בודקים.

| מה | איפה |
|---|---|
| **חומר גולמי** — מצגות, מסמכים, סיכומי דיונים, ראיונות, תמונות | [מיקום החומר הגולמי] |
| **תוצרים** — פרסונה, Lean Canvas ושאר הישויות החיות | `תוצרים/` ב-repo הזה — תמיד, בכל מיזם. זה מה שהסוכנים קוראים וכותבים |
| **גרסת הפלייבוק** — המתודה והסוכנים שהמיזם עובד לפיהם | `main` (הגרסה החיה). לנעילה — שם תגית, למשל `v0.2`: הסוכנים יקראו ממנה, ומחזור שרץ לא ישתנה באמצע |

## איך עובדים עם סוכן

> המדריך המלא: [המדריך למנטור לעבודה עם ה-Playbook](https://claude.ai/artifact/TDTCr53RVNnHw4VhX5XCfg).

פותחים את ה-repo הזה ב-Claude Code (או Kiro / Antigravity) ומקלידים `/run-agent <שם הסוכן>` — למשל `/run-agent פרסונה דיגיטלית`. הסוכן קורא את המפרט מהפלייבוק ואת החומרים מכאן / מ-Drive, מתשאל את הצוות, ואחרי אישור כותב את התוצר ל-`תוצרים/`.

לסוכנים של יום 1 יש **סקילים ייעודיים** (`gov-labs-challenge-space`, `gov-labs-persona-card`, `gov-labs-persona-visual`, `gov-labs-assumptions-interview-guide`). אפשר להפעיל אותם בשמם, ו-`/run-agent` מעביר אליהם לבד.

**פעם אחת בכל מחשב:** מחברים את ה-repo לפלייבוק (ול-Drive, אם החומר שם) — מתוך תיקיית הפלייבוק:

```bash
bash skills/run-agent/connect.sh "<נתיב ל-repo הזה>" ["<תיקיית המיזם ב-Drive for desktop>"]
```

## מה יש כאן

| תיקייה | מה |
|---|---|
| `תוצרים/` | התוצרים של המיזם, קובץ לכל תוצר. אותם שמות כמו `02-תוצרים-וטמפלטים/` בפלייבוק — כאן ממלאים אותם בפועל. ריק בהתחלה. |
| `ימים/` | תיקייה לכל יום בתוכנית (אותם שמות כמו `01-ימים/` בפלייבוק): סיכומי מפגש, שיעורי בית והחלטות של היום, ב-MD. |
| `ידע/` | חומר גולמי — **רק אם** נבחר למעלה. תיקייה לכל נושא, תאריך בשם כשרלוונטי. אם החומר הגולמי ב-Google Drive — נשאר ריק. |
| `.kiro/steering/` | הגדרות הסוכן של המנטור. מצביע חזרה לפלייבוק — התהליך, הכללים והשפה מוגדרים שם, לא כאן. |

## מי עובד כאן

- הקבוצה — דרך המנטור.
- המנטור — עם הסוכן, שרואה גם את הפלייבוק וגם את ה-repo הזה.

## איך התוצרים נוצרים

לכל תוצר יש הגדרה בפלייבוק (`02-תוצרים-וטמפלטים/`) — מה זה, המבנה, איך מייצרים. כאן נמצא רק המילוי של המיזם.
