# הלוח החי — מפת אמפתיה שנבנית על המסך

כלי עזר של הסקיל `gov-labs-persona-card`. בזמן תשאול הפרסונה ([Unboxing, תהליך 3](../../01-ימים/01-Unboxing/תהליכים/3-הגדרת-פרסונות-דיגיטליות-ומפת-אמפתיה.md)) הצוות רואה על מסך אחד את השאלה, עונה עליה, ורואה את ארבעת הרבעים מתמלאים.

**הלוח הוא כלי עבודה לחדר, לא התוצר.** התוצר נשאר [כרטיס הפרסונה](../../02-תוצרים-וטמפלטים/כרטיס-פרסונה-דיגיטלית-ומפת-אמפתיה.md) ב־Markdown.

## מתי להשתמש

| מתאים | לא מתאים |
|---|---|
| תת־צוות שיושב מול מסך או מקרן אחד, והמנטור רוצה שכולם יראו וישתתפו | סביבת עבודה בלי הרצת פקודות או בלי Python 3 |
| כשהבעיה היא ש"מפעיל ה־AI מקליד והשאר מסתכלים" | עדכון של כרטיס קיים אחרי ראיון שטח — שם עובדים ישירות על הכרטיס |
| סשן ראשון של פרסונה, כ־30 דקות | סוכן בצ'אט בלבד, בלי גישה לקבצים של ה־repo |

בלי הלוח הסקיל עובד כרגיל, בשיחה. הלוח לא משנה את כללי התשאול.

## מה צריך

- Python 3 על המחשב של המנטור. אין התקנות — ספריית התקן בלבד.
- סוכן שרץ בתוך ה־repo של המיזם, יכול להריץ פקודות ולכתוב קבצים.
- דפדפן. אינטרנט נדרש רק לגופנים; בלעדיו הלוח עובד עם גופן המערכת.

הכול רץ על המחשב של המנטור בלבד (`127.0.0.1`). שום דבר לא יוצא ממנו — **חוץ מדיבור:** כשמשתמשים במיקרופון, הדפדפן שולח את ההקלטה לתמלול אצל ספק הדפדפן (בכרום — Google). אם התוכן רגיש, מקלידים ולא מדברים.

## איך מתחילים

מתוך ה־repo של המיזם:

```bash
python3 .playbook/skills/gov-labs-persona-card/assets/live-board.py serve --dir .live
```

הפקודה מדפיסה כתובת (ברירת מחדל `http://127.0.0.1:8765/`; אם הפורט תפוס — הפורט הפנוי הבא). פותחים אותה בדפדפן ומקרינים. מכאן הסוכן מנהל את הסשן, והצוות עובד רק מול המסך.

`.live/` לא נכנס לקומיט (הוא ב־`.gitignore` של תבנית המיזם).

## מה קורה על המסך

1. **פתיחה.** חלון שמסביר את המטרה ואת השלבים. לוחצים "מתחילים".
2. **שאלות כלליות.** כל שאלה נפתחת לבד בחלון: מה האתגר, את מי רואים, מה הוא מנסה להשיג. אחרי "שלח" מחכים לסוכן, כי התשובה קובעת את השאלה הבאה. התשובות נשארות על המסך: האתגר והיעד בכותרת, הפרסונה במרכז הלוח.
3. **ארבעת הרבעים.** המנטור לוחץ על רבע — אומרת, חושבת, מרגישה, עושה — והשאלה של אותו רבע נפתחת. לכל תשובה חובה לבחור **על מה היא נשענת** (למשל: שמענו ממנה / שמענו מאחרים / משוער), ואפשר להוסיף פירוט. הפריט מופיע על הלוח מיד והחלון נסגר; לא מחכים לסוכן, וממשיכים לרבע הבא. הסוכן מעבד ברקע ומעדכן לכל רבע שאלת המשך.
4. **"סיימנו".** הסוכן כותב את כרטיס הפרסונה, מפיק ממנו את התצוגה החזותית (`gov-labs-persona-visual`), ופותח את הקובץ בלשונית נפרדת. הלוח מציג את התקדמות ההפקה, ובסופה קישורים לקבצים.

**דיבור במקום הקלדה:** בכל חלון שאלה יש כפתור מיקרופון. לוחצים, מדברים בעברית, ולוחצים שוב לסיום — הטקסט נכנס לתיבה ואפשר לתקן אותו לפני השליחה. בפעם הראשונה הדפדפן מבקש הרשאה למיקרופון. בדפדפן בלי זיהוי דיבור הכפתור לא מוצג.

"דלג" זמין בכל שאלה. `Ctrl/Cmd+Enter` שולח, `Esc` סוגר.

**כמה נכנס ברבע:** עד כארבעה פריטים בגודל מלא. מעבר לזה הטקסט קטן מעט, אחר כך הרבע עובר לשני טורים, ואז ממשיך לקטון. נבדק עד עשרה פריטים ברבע במסך 1440×810.

## מה נשאר בסוף

| קובץ | מה | נכנס ל־git |
|---|---|---|
| `תוצרים/כרטיס-פרסונה-דיגיטלית-ומפת-אמפתיה-<כינוי>.md` | הכרטיס — התוצר | כן, אחרי אישור הצוות |

## לסוכן: איך מפעילים את הלוח

הסוכן לא עורך HTML. הוא קורא תשובות וכותב קובץ מצב אחד.

**לקרוא תשובות** — פקודה שממתינה עד שיש תשובה חדשה, מדפיסה אותה כשורת JSON ויוצאת:

```bash
python3 .playbook/skills/gov-labs-persona-card/assets/live-board.py wait --dir .live --after <מספר התשובה האחרונה שעובדה>
```

אם אין תשובה עד סוף הזמן (ברירת מחדל 540 שניות) מודפס `TIMEOUT`, ומריצים שוב. כמה תשובות שהצטברו מודפסות יחד. כל שורה: `id`, `time`, `who`, `kind` (`start` / `answer` / `skip` / `finish`), `text`, `quadrant` (`says` / `thinks` / `feels` / `does`, או ריק בשאלה כללית), `basis_kind`, `basis_text`.

**לעדכן את הלוח** — לכתוב את `.live/state.json` במלואו. הדף קורא אותו כל שנייה:

| שדה | מה |
|---|---|
| `phase` | `intro` — חלון הפתיחה · `general` — שאלות כלליות · `map` — ארבעת הרבעים |
| `question` | `{text, to}` — השאלה הכללית הנוכחית. שאלה חדשה נפתחת לבד |
| `quadrant_questions` | `{says: {text, to}, …}` — השאלה שנפתחת בלחיצה על כל רבע |
| `quadrants` | `{says: [{text, by, basis, conf, new}], …}` — הפריטים. `new` לסבב האחרון בלבד |
| `challenge`, `jtbd`, `persona: {name, nick}`, `subteam` | מה שמוצג בכותרת ובמרכז |
| `open` | רשימת מחלוקות ושאלות פתוחות, בלי הכרעה |
| `answered` | מספר התשובה האחרונה שעובדה. **חובה לעדכן** — עד אז הדף מציג המתנה |
| `finish` | `{steps: [{text, status: done / doing / todo}]}` — התקדמות ההפקה |
| `result` | `{html, md, title}` — שמות הקבצים ב־`תוצרים/`, כשהם מוכנים |
| `intro`, `basis_options` | אופציונלי — להחליף את טקסט הפתיחה או את אפשרויות הבסיס |
| `updated` | שעת העדכון, מוצגת בתחתית |

**סדר העבודה:** מצב ראשון עם `phase: "intro"` → `wait` → על `start` כותבים שאלה כללית ראשונה → `wait` וחוזר חלילה → אחרי השאלות הכלליות `phase: "map"` עם שאלה לכל רבע → על כל תשובה מוסיפים את הפריט, מחליפים את שאלת הרבע בשאלת המשך ומקדמים את `answered` → על `finish` כותבים את הכרטיס, מריצים את הסקיל החזותי, ומדווחים דרך `finish` ו־`result`.

**הכללים של הסקיל חלים גם כאן:** רק מה שנאמר בחדר, בניסוח של הצוות. הבסיס הוא מה שהצוות בחר — הסוכן לא מנחש אותו. כל פריט הוא השערה. הכרטיס נכתב מהשיחה, לא מהלוח.

## כשמשהו לא עובד

| מה רואים | מה עושים |
|---|---|
| "אין חיבור לשרת המקומי" בתחתית | השרת נעצר. מריצים שוב את פקודת `serve`; המצב נשמר ב־`.live/` והלוח חוזר לאותה נקודה |
| החלון נשאר על "הסוכן קורא את התשובה" | הסוכן לא עדכן את `answered`, או שהוא לא ממתין. בודקים שפקודת `wait` רצה |
| פריט נשאר צהוב עם סימן טעינה | אותו דבר — התשובה נשלחה ונשמרה, הסוכן עוד לא עיבד אותה |
| הכתובת לא נפתחת | הפורט שונה מברירת המחדל. הכתובת הנכונה היא מה ש־`serve` הדפיס |
| רוצים להתחיל מחדש | מוחקים את `.live/answers.jsonl` וכותבים מצב ראשון עם `phase: "intro"` |

## מגבלות ידועות

- **הבדיקה נעשתה בסשן אחד, עם משתתף אחד, על מחשב אחד.** לא נבדק עם תת־צוות אמיתי, עם שני תתי־צוותים במקביל, על Windows, או במסך 1920×1080.
- **"סיימנו" מדלג על סקירת הצוות.** הסקיל החזותי מצפה לכרטיס שהצוות בדק; דרך הכפתור הכרטיס נכתב ומופק ברצף, והצוות רואה אותו רק בסוף.
- **אין תמונה בלי כלי ליצירת תמונות.** התצוגה מציגה מציין מקום גלוי.
- **שני תתי־צוותים על אותו מחשב** צריכים שני שרתים, כל אחד עם `--dir` ופורט משלו.
- **דיבור נבדק רק בהופעת הכפתור.** התמלול בעברית, ההרשאה למיקרופון והשגיאות לא נבדקו במיקרופון אמיתי.
- **כותרות הרבעים בלשון נקבה** (אומרת, חושבת…), כמו בפלייבוק, גם כשהפרסונה גבר.
