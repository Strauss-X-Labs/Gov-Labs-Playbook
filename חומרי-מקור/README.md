# חומרי מקור

החומר הגולמי שהפלייבוק מתבסס עליו. **נשאר לתמיד** — זה ה-provenance: כשמישהו שואל "מאיפה זה הגיע?", התשובה כאן.

| תיקייה | מה |
|---|---|
| `מסמכים/` | מצגות, מסמכים, ייצוא מ-SharePoint, חומרים מ-Gov-Labs 1 — כל פורמט. שם: `נושא-מקור-תאריך.סיומת` |
| [תמלולי-פגישות/](תמלולי-פגישות/) | תמלולי פגישות צוות. ההחלטות שנלקחו שם הופכות לתוכן בפלייבוק |
| [לא-ממוין/](לא-ממוין/) | לא ברור לאן? לכאן. זמני — הצוות המרכזי ממיין |
| [סטטוס.md](סטטוס.md) | מצב כל קובץ: חדש / נבחן / שולב / לא רלוונטי, ולאיזה חלק בפלייבוק הוא נוגע |
| `_טקסט/` | המרה אוטומטית של מצגות ומסמכים לטקסט, כדי שסוכן יוכל לקרוא. cache — לא עורכים |

## הוספת חומר חדש

1. שים את הקובץ בתיקייה המתאימה.
2. הרץ את ה-skill `scan-sources` (ב-Claude Code / Kiro / Antigravity), או ידנית: `python3 skills/scan-sources/scan.py`.
   פעם ראשונה במחשב: `pip install -r skills/scan-sources/requirements.txt` (בשביל PDF).
3. ה-skill בוחן את החומר מול הפלייבוק וכותב המלצה ב-[סטטוס.md](סטטוס.md). השילוב עצמו — אחרי אישור.

## כלל אחד

חומר מקור לא עורכים. אם משהו במקור השתנה — הגרסה החדשה נכנסת לצד הישנה, עם תאריך בשם.
