# מיפוי מסע קיים (Current Journey Map)

> מקור: [0.2 methods_.docx](../../חומרי-מקור/מסמכים/אביבית/0.2%20methods_.docx) — תוכן ההרצאות של Gov-Labs, כפי שתועד ע"י אביבית.

## מהות

כלי שמאפשר להתקדם בתהליך "חוקי" — לזהות ולעבור על השלבים שהמשתמש עובר בתוך ומחוץ למוצר או לשירות. המפה ממחישה ומפרטת את התהליך, ותחתיו נבנים ממדים נוספים: מה המשתמש מרגיש בכל שלב, מה הוא חושב, איפה הוא נמצא, עם מי הוא באינטראקציה, ודרך איזה ערוץ הוא מתקשר עם המוצר.

## מבנה המפה

טבלה. ציר אופקי — שלבי המסע (שלב 1, שלב 2, …). לכל שלב, שכבות מידע:

| שכבה | מה |
|---|---|
| **מטרת הפרסונה** | מה היא מנסה להשיג בשלב הזה |
| **נקודת ממשק / מיקום** | איפה — פיזית או דיגיטלית — מתרחשת האינטראקציה |
| **בעלי עניין** | מי מעורב בשלב |
| **חושבת** | מה עובר לה בראש |
| **מרגישה** | הרגש. **כאן מסומנים החסמים ונקודות הכאב / החיכוך** |
| **זמן** | כמה השלב לוקח |
| **עקומת סנטימנט** | קו גרפי — עלייה וירידה בשביעות הרצון / המצוקה לאורך כל המסע |
