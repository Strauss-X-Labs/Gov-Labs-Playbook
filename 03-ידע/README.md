# 03 — ידע

ידע כללי שלא שייך ליום אחד. קובץ לכל פריט, שם קובץ = שם הפריט.

- `מתודות/` — קובץ לכל מתודה, **כולן באותה רמה, בלי מספור**. Design Thinking היא מתודה שמסגרתה מודל היהלום; מודל היהלום עצמו לא. 5 Whys, HMW, What If, פרסונה — כן. `זרימת-המתודות.md` פותח: כל מתודה stand-alone, וביחד תהליך אחד.
- `סטנדרטים/` — best practices, סטנדרטים של ארכיטקטורה ופיתוח. (ה-`knowledge` וה-`steering/tech` מה-repo של אסף עוברים לכאן.)

ידע שהוא **ספציפי למיזם** לא נכנס לכאן — הוא חי ב-`ידע/` ב-repo של המיזם.
