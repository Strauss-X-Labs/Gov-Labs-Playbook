# המסע

## שמונה מפגשים, שלושה צירים

התוכנית בנויה משמונה מפגשי ליבה על פני שלושה צירים מקבילים: **המוצרי**, **הפיתוח** ו**העסקי**. השינוי המבני הגדול מ-1.0: ציר הפיתוח מתחיל ב-Lean Canvas, לא בסוף.

| ציר | תחנות |
|---|---|
| **עסקי** | בעיות → בעלי עניין → מודל כלכלי → **Lean Canvas** → מדדי ROI |
| **מוצר** | פרסונות → מסע משתמש → קונספט → User Testing |
| **פיתוח וארכיטקטורה** | (מ-Lean Canvas) → Spec-Driven Dev → Backlog → מוצר אמיתי לאימות |

## מצבי הפעולה — מרעיון למוצר (Ideo-Based)

התהליך לא מתפזר — הוא מחולק למצבים מוגדרים. מה שקורה **בין** המפגשים הוא חלק מהתוכנית, לא הפסקה.

| מצב | מתי | מה קורה |
|---|---|---|
| **חקר** (Exploration) | יום 1 — Unboxing | פתיחת מרחב האתגר, הרחבת הפריזמה, מיפוי כל מה שאיננו יודעים |
| **לולאת למידה** (Learning Loop) | שבועיים בין יום 1 ליום 2 | יציאה לשטח, ראיונות עומק, איסוף עדויות, מילוי מובנה של ה-Challenge Space Canvas |
| **יצירה / רעיונאות** (Creation) | ימים 2–3 — חשיבה עיצובית | עבודה מעבדתית אינטנסיבית וסגורה ("בלי זמן לצאת לשטח"): מיפוי מסע קיים ע"י האדם, אזורי הזדמנות, Re:design מאפס, המחשת קונספט |
| **לולאת תיקוף** (Validation Loop) | שבועיים בין יום 3 ליום 4 | בדיקת קונספט מול משתמשים אמיתיים בשטח. אישוש או הפרכת היפותזות הכאב וסוג המענה — **לפני** ה-Lean Canvas |
| **אסטרטגיה מוצרית** | יום 4 — Lean Canvas | נקודת בשלות ותכלול |
| **מאסטרטגיה למוצר** | ימים 5–8 | הגדרת ה-MVP ובניית המוצר |

### הפגישה השבועית של הצוות

לכל צוות **פגישה שבועית קבועה** בין המפגשים. שם הנציגים מציגים את ה-PRD-גג v0.1 אחרי יום 4, ושם הקבוצה מאשרת את ה-PRD v1.0 אחרי יום 5. *[פגישת הצוות האמצעית](../01-ימים/01-Unboxing/סקירה.md) שאחרי ה-Unboxing היא כנראה הראשונה מהן. טרם אומת.*
