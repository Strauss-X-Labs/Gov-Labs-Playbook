# 02 — טמפלטים ותוצרים משמעותיים

לא לכל דבר. שני סוגים, שניהם קובץ אחד לכל אחד:

- **טמפלט** — תבנית שהוגדרה מראש ומתמלאת מאחורי הקלעים תוך כדי העבודה. הגייט הוא לראות שהיא מלאה. (Challenge Space Canvas)
- **תוצר משמעותי** — מה שסוכן או תהליך מייצר, ושהצוות ממשיך לעבוד איתו. (כרטיס פרסונה ומפת אמפתיה)

הקבצים כאן **שטוחים**, לא בתוך ימים — כי פרסונה שנולדה ב-Unboxing חיה עד Storytelling. התהליך שממלא אותם מקשר לכאן.

**ישויות חיות:** פרסונה, לין קנבס, מרחב האתגר — ממשיכים להתעדכן לאורך כל התוכנית. ראה [עקרונות רוחב](../04-AI/עקרונות-רוחב.md).
