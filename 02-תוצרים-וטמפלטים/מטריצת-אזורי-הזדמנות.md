## מה זה ולמה

טבלת השוואה מנומקת של 4 אזורי ההזדמנות שנבחנו: פירוט ניתוח האימפקט מול מורכבות, הנימוקים בעד ונגד כל אזור, והחלטת הצוות על תחום המיקוד המוביל — עם תיעוד הנימוק. זה מה שמונע את הקפיצה הפזיזה ממסע לבעיה נקודתית: רואים שהיו ארבע אפשרויות, ולמה נבחרה אחת.

## המבנה

```markdown
# מטריצת אזורי הזדמנות — [שם המיזם]
> מקור: מפת המסע הקיים + דוח הסינתזה · נוצר: [יום DT1]

| | 1. מניעתי / פרואקטיבי | 2. פישוט והנגשה רדיקלית | 3. העצמת עובד המדינה | 4. אמון ושקיפות |
|---|---|---|---|---|
| **מה האזור** (הצעת הסוכן) | | | | |
| **מקבצי החיכוך שהוא נוגע בהם** | | | | |
| **משפר קיים או משנה פרדיגמה?** | | | | |
| **אימפקט רחב למדיניות?** | | | | |
| **בר-קיימא ליישום?** | | | | |
| **דירוג הסוכן: אימפקט / מורכבות** | | | | |
| **בעד** | | | | |
| **נגד** | | | | |
| **הצבעה** (3 נקודות לחבר) | | | | |

## האזור הנבחר
**[שם האזור]**
**הנימוק:** [למה דווקא זה — מה שכנע]
**מה נדחה ולמה:** [שורה לכל אזור]
**חתך המנטור:** [אם היה]
```

## מי ממלא ומתי

- **DT1 תהליך 3:** הסוכן מציע 4 אזורים; הצוות ממלא את 3 השאלות, בעד/נגד, מצביע; המנטור חותך.
- **DT1 תהליך 4:** האזור הנבחר הוא הקלט ל-5 Whys.

## איך זה ממשיך לחיות

חד-פעמי יחסית — אבל שלושת האזורים שנדחו לא נזרקים. הם חוזרים ב-Roadmap (יום 7) כ"מה הלאה אחרי ה-MVP".
