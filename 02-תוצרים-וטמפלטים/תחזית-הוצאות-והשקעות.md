## מה זה ולמה

תחזית ההוצאות וההשקעות של המיזם לתקופת מפת הדרכים, כולל ההנחות שמאחוריה. נבנית מעל ה-[Roadmap](מפת-דרכים-תקציב-וסיכונים.md) הנעול, ומאותגרת לפני שהמספרים ננעלים. נקודת הפתיחה: מרכיבי ההוצאה מההכנה, ו-Cost Structure ב-[לוח Lean Canvas](לוח-Lean-Canvas.md).

> ⚠ **חפיפה עם הטמפלט הקיים:** במקור של אביבית ([7 Roadmap.docx](../חומרי-מקור/מסמכים/אביבית/7%20Roadmap.docx)) התוצר הוא אחד — "מפת דרכים אסטרטגית, תוכנית תקציב וסיכונים". במתווה החדש התחזית היא **קובץ נפרד**. נוצר כאן קובץ נפרד ל"תחזית", והטמפלט הקיים נשאר כמטריה. ממתין להחלטה.

## המבנה (הטמפלט עצמו)

קובץ Excel, `תחזית-הוצאות-והשקעות.xlsx`, שני טאבים (נוצרים ע"י [תחזית הוצאות + CFO סקפטי](../04-AI/סוכנים/תחזית-הוצאות-ו-CFO-סקפטי.md)):

**טאב 1 — הנחות יסוד:** כל ההנחות — מספרים בודדים, וטבלאות של נתונים שמשתנים לאורך זמן (ערך לכל תקופה, למשל מספר משתמשים). לכל הנחה: ערך · יחידה · מקור (`קבוצה` / `בנצ'מרק` / `הערכה — הסוכן`) · טווח אופטימי / סביר / פסימי, אם קיבלה טווח ב-CFO.

**טאב 2 — תחזית הוצאות:** רבעונית. **כל מספר הוא נוסחה** שמפנה לטאב הנחות היסוד — שינוי בהנחה משנה את כל התחזית.

| | שלב 1 — [שם] | | שלב 2 — [שם] | | … | | |
|---|---|---|---|---|---|---|---|
| | רבעון 1 | רבעון 2 | רבעון 3 | רבעון 4 | … | **סה"כ ל-[N] חודשים** | **איך מחושב** |
| **הוצאות משתנות** | | | | | | | |
| [סעיף — למשל מחשוב / טוקנים] | | | | | | | [למשל: 0.4 ₪ למשתמש פעיל בחודש × משתמשים בשלב × 3 חודשים] |
| [סעיף — למשל מוקד שירות] | | | | | | | [למשל: משרה לכל 100 מפעלים · 165 שעות לחודש (495 לרבעון) · 95 ₪ לשעה] |
| **הוצאות קבועות** | | | | | | | |
| [סעיף — למשל כוח אדם קבוע] | | | | | | | |
| [סעיף — למשל רישיונות] | | | | | | | |
| **סך הוצאות לרבעון** | | | | | | | |
| **סך הוצאות לתקופה** | | | | | | | |

- **שורה ראשונה** — שלבי ה-Roadmap; **שורה שנייה** — ציר הזמן ברבעונים.
- **משתנות** — גדלות עם מספר המשתמשים (ענן, טוקנים, שיווק, תמיכה ושירות). **קבועות** — לא תלויות בו (כוח אדם קבוע, פיתוח, רישיונות, מערכות מידע).
- **שורה לפני אחרונה** — סך לכל רבעון. **שורה אחרונה** — סך לכל שלב, על פני כל שלבי ה-Roadmap.
- **עמודת "סה"כ ל-[N] חודשים"** — סך כל סעיף על פני כל התקופה. N = אורך ה-Roadmap בחודשים.
- **עמודת "איך מחושב"** — העמודה השמאלית ביותר, ליד הסה"כ. משפט לכל שורה: מה המנגנון, וההנחות עם המספרים שלהן. למשל: *"משרה לכל 100 מפעלים · 165 שעות לחודש (495 לרבעון) · 95 ₪ לשעה"*. מי שקורא את הטבלה מבין כל שורה בלי לפתוח את טאב הנחות היסוד. המספרים במשפט נלקחים מטאב הנחות היסוד בנוסחה (`TEXT`), כדי שהמשפט יתעדכן כשההנחה משתנה. בשורות הכותרת והסיכום — ריק, או "סכום השורות שמעל".

**העיצוב** — קובץ שמציגים למנהלים, לא טיוטת עבודה:
- **מימין לשמאל** — שני הטאבים.
- **כותרות** — שורת השלבים ושורת הרבעונים מודגשות על רקע כהה, ותאי השלב ממוזגים מעל הרבעונים שלו. גבול עבה בין שלב לשלב.
- **שורות הכותרת** "הוצאות משתנות" / "הוצאות קבועות" — רקע בהיר, מודגש, לכל רוחב הטבלה.
- **שורות הסיכום ועמודת הסה"כ** — מודגשות, ברקע משלהן, עם גבול עליון כפול מעל סך התקופה.
- **מספרים** — `₪ #,##0`, בלי אגורות. יישור אחיד בכל הטבלה.
- **"איך מחושב"** — רחבה (כ-60 תווים), גלישת טקסט, גופן אפור ורגיל, כדי שלא תתחרה במספרים.
- **הקפאה** — שתי שורות הכותרת ועמודת שמות הסעיפים קבועות בגלילה.
- **טאב הנחות היסוד** — אותה שפה: כותרת, עמודות ערך · יחידה · מקור · טווח. **תאי קלט** (ערכים שמותר לשנות) — רקע צהוב בהיר, כדי שיהיה ברור איפה משנים. עמודת המקור צבועה לפי סוג: `קבוצה` / `בנצ'מרק` / `הערכה — הסוכן`.
- **רוחב עמודות** מותאם לתוכן; אין `####`. מוכן להדפסה — לרוחב, בעמוד אחד.

**במיזם:** `01-ימים/07-Roadmap/תוצרים/תחזית-הוצאות-והשקעות.xlsx`, ולידו `תחזית-הוצאות-והשקעות.md` — מקור האמת לתוכן: מרכיבי ההוצאה מההכנה, הסעיפים שאושרו, ההנחות, תוצאות ה-CFO, השאלות שסומנו ל-Q&A והקישור לקובץ. המנטור/ית מעלה את הקובץ לדרייב של הקבוצה.

**לוח ה-CFO:** `תחזית-הוצאות-והשקעות-CFO.html`, מהתבנית [cfo-board.html](../skills/tools/assets/roadmap/cfo-board.html). בלוח כל הנחות היסוד, כשהמאותגרות צבועות, ו-3–4 שאלות האתגור. לכל שאלה יש תיבת תשובה לקבוצה וצ'קבוקס "להוסיף ל-Q&A", שאינו מסומן כברירת מחדל. עונים בלוח, ובסוף לוחצים "העתקת סיכום" ומדביקים למוח.

**קלט מההכנה:** מרכיבי ההוצאה — חלק 3 בלוח ההכנה ([היערכות](../01-ימים/07-Roadmap/היערכות-למפגש.md)): לכל מרכיב קבועה / משתנה, איך נמדד, וידוע / הערכה / לא ידוע, **בלי סכומים**. המוח קורא אותם ל-MD, סעיף "מרכיבי הוצאה (מההכנה)".

## מי ממלא ומתי

בהפסקת הצהריים הסוכן מנתח את ה-Roadmap ומכין Draft 0 של הסעיפים וההנחות. בסשן ([תהליך 4](../01-ימים/07-Roadmap/תהליכים/4-תחזית-הוצאות-ואתגור-CFO-סקפטי.md)) הקבוצה מאשרת סעיפים, קובעת או מאשרת הנחות, עוברת אתגור CFO — ואז הסוכן בונה את התחזית והקובץ.

**"גמור" לסוף היום:**
- תחזית רבעונית לכל תקופת מפת הדרכים, עם חלוקה למשתנות וקבועות ושתי שורות הסיכום.
- כל מספר בטאב התחזית הוא נוסחה; לכל הנחה יש מקור.
- 3–4 ההנחות המשפיעות ביותר עברו אתגור מפורש ב-CFO סקפטי, וקיבלו טווח איפה שלא הייתה תשובה חד-משמעית.
- מבוסס על מפת הדרכים שננעלה ב[תהליך 3](../01-ימים/07-Roadmap/תהליכים/3-תיקוף-מפת-הדרכים.md).
