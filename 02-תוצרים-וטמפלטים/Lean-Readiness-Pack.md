## מה זה ולמה

עונה על שאלה אחת: **האם ה-repo והחומרים מוכנים כדי לגבש Lean Canvas, ומה צריך להשלים?** זו **בדיקה בלבד**: מה נמצא, על מה אפשר להישען, מה חסר ואיך משלימים. היא **לא** מנסחת את הקנבס — הטיוטה הראשונה היא תוצר נפרד, [Draft 0](Draft-0-Lean-Canvas.md).

האחריות שלה מסתיימת כשהעבודה על הקנבס מתחילה. מכאן הסטטוס מנוהל ב[לוח Lean Canvas](לוח-Lean-Canvas.md). *(החלטת ליאור, [2026-09-23](../חומרי-מקור/תמלולי-פגישות/2026-09-23-רונית-ליאור-lean-canvas.md): מבנה נתונים אחד לכל דבר.)*

## המבנה

```markdown
# Lean Readiness — [שם המיזם]
> נבדק: [תאריך] · עודכן: [תאריך] · **מצב כללי: מוכן / מוכן עם פערים / לא מוכן**
> נוצר ע"י: [סוכן] · מקורות: [הקבצים שנקראו]

## 1. התוצרים ב-repo
| תוצר | נמצא? | איפה | הערה |
|---|---|---|---|

## 2. מוכנות לקוביות 1, 2, 5
| נושא | יש מספיק חומר? | סטטוס | על מה נשען (קובץ וסעיף) | מה חסר |
|---|---|---|---|---|
| **לקוחות** — פלחים, היקפים, Early Adopters | כן / חלקית / לא | ✓ / ~ / ? / ⚡ | | |
| **בעיות** — נתונים, גודל הבעיה | | | | |
| **אלטרנטיבות קיימות** | | | | |
| **הצעת ערך ייחודית** | | | | |

## 3. תוצאות בדיקת הקונספט
מה אושש · מה הופרך · מה לא נבדק — או: "עוד לא התקבלו".

## 4. סתירות
[מידע שמתנגש עם הנחה או החלטה קיימת]

## 5. המלצות להשלמת פערים
| # | הפער | ההמלצה | מי | עד מתי | חוסם את Draft 0? |
|---|---|---|---|---|---|

## חסר ב-repo
[תוצרים שלא נמצאו ב-repo, והוחלט להמשיך בלעדיהם. זה לא פער בתוכן]
```

**המצב הכללי:**
- **מוכן** — כל ארבעת הנושאים "כן", ואין המלצה חוסמת.
- **מוכן עם פערים** — אפשר לכתוב Draft 0, והפערים מסומנים בו.
- **לא מוכן** — חסרה הגדרת הבעיה או הצעת הערך, או שיש המלצה חוסמת. משלימים לפני Draft 0.

## התצוגה — `Lean-Readiness-Pack.html`

נבנית מה-MD המאושר, לפי [readiness.html](../skills/run-agent/assets/lean-canvas/readiness.html): שורת מצב כללי בראש, טבלת התוצרים, ארבעת הנושאים עם סטטוס בצבע, וההמלצות כרשימת משימות. מיועדת למנטור ולצוות, על מסך או מודפסת.
