# סוכנים

**קובץ לכל סוכן** — סקופ (מתי + טריגר), קלטים, פלטים, והנחיית הפעלה. זה המפרט שממנו הסוכן נבנה. התהליכים מקשרים לכאן ולא מעתיקים.

סוכני AI הם חברי צוות קבועים של כל מיזם, ונשארים איתו גם אחרי התוכנית.

|---|---|---|
| *(נוצרים תוך כדי שילוב הימים)* | | |
