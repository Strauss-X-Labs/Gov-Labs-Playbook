## סקופ וטריגר
עבודה **לצד איש העיצוב והפיתוח** בסדנה, בסשן הפיתוח והעיצוב. לא סוכן שרץ לבד — שיח מתמשך: הצוות מדבר, הסוכן משנה קוד בזמן אמת.

## קלטים
1. מסכי Figma המבוססים על קומפוננטות ה-Design System הממשלתי.
2. תרשים זרימת ה-MVP ([מפרט MVP](../../02-תוצרים-וטמפלטים/מפרט-MVP.md)).
3. ספריית הרכיבים הממשלתית (Tailwind CSS / React Components).
4. קבצי ה-MD של המיזם — מפרט ה-Core Loop, מטריצת הרכיבים, הנחיות Design System.

## פלטים
1. **קוד פרונטנד נקי ותקני** (React / Tailwind / Web Components) המוכן ישירות לחיבור לסביבת הפיתוח.
2. **מחולל קוד פרונטנד אוטומטי** המקצר את זמן המעבר לפיתוח.
3. **Mock Data** — דרך Mock API Generator: קבצי JSON מדומים ומדויקים המדמים תגובות מערכות ליבה ושכבות AI (תעודות זהות מדומות, PDF לדוגמה, תשובות סוכן אנליטיקה).

## הסביבה
Figma Make / Figma-to-Code · Cursor / Claude Code / v0 · Mock API Generator. Tool-Agnostic — ראה [גישת AI](../../00-התוכנית/גישת-AI.md).
