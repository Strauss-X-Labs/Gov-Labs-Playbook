# 04 — AI

התוכן שהסוכנים משתמשים בו — לא הקוד שלהם (הקוד ב-`.kiro/`).

- [סוכנים/](סוכנים/) — קובץ לכל סוכן: סקופ, קלט, פלט, הנחיית הפעלה.
- [עקרונות-רוחב.md](עקרונות-רוחב.md) — מה שנכון בכל יום ובכל תהליך, כתוב פעם אחת: Friendly Tips, Q&A, ישויות חיות, מפעיל ה-AI הצוותי.
- `גייטים/` — ההכנה לכל מפגש: מה הסוכן בודק שהקבוצה הביאה, על אילו חוסרים הוא מצביע. קובץ לכל גייט, באותו מספור כמו [01-ימים](../01-ימים/).
- `פרומפטים/` — פרומפט לכל שימוש. שם קובץ = מה הפרומפט עושה. בראש הקובץ: לאיזה תוצר, איזה מודל/כלי, מה הקלט.

**כל יכולת AI** — סוכן, פרומפט, או שימוש ביום — מתוארת בשלושה שדות:

| שדה | מה |
|---|---|
| **סקופ** | מתי משתמשים + מה מפעיל (טריגר) |
| **קלטים** | מה חייב להיות ביד לפני |
| **פלטים** | מה יוצא — והפלט הוא תמיד תוצר. לינק ל-`02-תוצרים-וטמפלטים/` |

**Agent / Skill / MD:** ה-MD הוא המקור — כל הידע, המתודות וההגדרות חיים כאן ומתעדכנים פעם אחת. Skill הוא operator קל: יודע *מתי* להפעיל ו*איזה* MD להביא, ומפנה אליו בלינק בלי לשכפל. Agent מעל ה-Skill ומפעיל אותו.

עיקרון: **פרומפט מצביע על תוצר**, לא מחליף אותו. ההגדרה של "פרסונה" חיה ב-`03-ידע/מתודות/`, הטמפלט ב-`02-תוצרים-וטמפלטים/`; הפרומפט רק עוזר לייצר אותה.
