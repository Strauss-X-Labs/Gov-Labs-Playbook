# 04 — AI

התוכן שהסוכנים משתמשים בו — לא הקוד שלהם (הקוד ב-`.kiro/`).

- [סוכנים.md](סוכנים.md) — ארבעת ה-Gems: מי הם ומה הם עושים.
- [גייטים/](גייטים/) — ההכנה לכל מפגש: מה הסוכן בודק שהקבוצה הביאה, על אילו חוסרים הוא מצביע.
- [פרומפטים/](פרומפטים/) — פרומפט לכל שימוש. שם קובץ = מה הפרומפט עושה.

**כל יכולת AI** — סוכן, פרומפט, או שימוש ביום — מתוארת בשלושה שדות:

| שדה | מה |
|---|---|
| **סקופ** | מתי משתמשים + מה מפעיל (טריגר) |
| **קלטים** | מה חייב להיות ביד לפני |
| **פלטים** | מה יוצא — והפלט הוא תמיד תוצר. לינק ל-`02-תוצרים/` |

**Agent / Skill / MD:** ה-MD הוא המקור — כל הידע, המתודות וההגדרות חיים כאן ומתעדכנים פעם אחת. Skill הוא operator קל: יודע *מתי* להפעיל ו*איזה* MD להביא, ומפנה אליו בלינק בלי לשכפל. Agent מעל ה-Skill ומפעיל אותו.

עיקרון: **פרומפט מצביע על תוצר**, לא מחליף אותו. ההגדרה של "פרסונה" חיה ב-`02-תוצרים/פרסונה.md`; הפרומפט רק עוזר לייצר אותה.
