## מתי להשתמש (מתי להשתמש)

- כאשר נרצה להציג את מספר ההודעות או עדכונים שמחייבים את תשומת לב המשתמש.
- בכדי להציג את מספר התוצאות שהוחזרו משאילתת חיפוש, בכך נעזור למשתמשים להבין את כמות המידע שהם מתמודדים איתה.
- כאשר יש מספר פריטים בעגלת הקניות או ברשימת משימות מספק סיכום ברור של הפריטים שנבחרו.

## מתי להימנע (מתי להימנע)

- כאשר התוכן אינו משתנה או שאינו דורש אינטראקציה עם המשתמש,
- כאשר  המספר לא ניתן להצגה כמספר יחיד, כמו טווחים או ממוצעים.
- כאשר המידע הוא בעל עדיפות נמוכה ואינו רגיש לזמן או קריטי לחוויית המשתמש.

## עשה ואל תעשה (עשה ואל תעשה)

במקרים בהם המספר גדול מ-999 יש להוסיף את הסימן + לצורך הצגת מספרים גדולים יותר.

אין להשתמש במספרים הגדולים מ-999.
