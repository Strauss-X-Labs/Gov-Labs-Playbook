## מתי להשתמש (מתי להשתמש)

- כאשר נדרש ממשק צ’אט/מסרים עם מערכת או נציג אנושי.
- כאשר המשתמש מתבקש להזין טקסט חופשי (שאלה, בקשה, מידע) במקום לבחור מתוך אפשרויות קבועות.
- כאשר נדרשת חוויית דיאלוג מתמשך – המשתמש שולח הודעה ומקבל תגובה.
- כאשר יש צורך להציע אייקוני פעולה נוספים בצמוד לשדה (שליחה, מיקרופון, העלאת קובץ).

## מתי להימנע (מתי להימנע)

- כאשר מדובר ב־חיפוש תוכן באתר/מערכת – שם יש להשתמש בשדה חיפוש ייעודי (Search Input) עם זכוכית מגדלת, הצעות אוטומטיות ותוצאות חיפוש.
- כאשר קיימת רשימת אפשרויות ברורה – עדיף להשתמש ברכיבי בחירה (Dropdown, Select, Radio Group) ולא לאפשר טקסט חופשי.
- כאשר מדובר בהזנת מידע מובנה (מספר טלפון, תאריך, אימייל) – יש להשתמש באינפוט מתאים עם ולידציה ולא בשדה טקסט כללי.

## עשה ואל תעשה (עשה ואל תעשה)
