## אנטומיה (אנטומיה)

Field Label

טקסט שמתאר למה לצפות מרשימת האפשרויות הנפתחת.

Mandatory

סימון שדה חובה- אופציונלי.

Tooltip Icon

אייקון שפותח Tooltip. נדרש ליצור Tooltip ובו ההסבר הנוסף-  אופציונלי. (יש לבחור או -Tooltip Icon או - Question Tooltip. שני הרכיבים לא יופיעו לעולם זה לצד זה)

Question Tooltip

שאלה מניעה לפעולה שמובילה לפתיחת Tooltip. נדרש ליצור Tooltip ובו ההסבר הנוסף- אופציונלי.  (יש לבחור או -Tooltip Icon או - Question Tooltip. שני הרכיבים לא יופיעו לעולם זה לצד זה)

Help Text

נשתמש למידע קריטי שיסייע להשלמת הפעולה (קיים רק במצב Error).

Field Text

מציג את האפשרות שנבחרה כעת או הנחיה כברירת מחדל.

Field

האלמנט שלחיצה עליו פותחת את הרשימה.

Dropdown Icon

חץ מופנה מעלה/ מטה, תלוי האם הרכיב במצב פתוח או סגור.

List Container

מכיל את רשימת האפשרויות הניתנות לבחירה. מוצג במצב פתוח.

List Item

אפשרות אחת מתוך סך האפשרויות המוצגות ב-List Container.

Header

כותרת שמאפשרת לארגן יחד סוגים של אפשרויות.

Icon

סמל שמופיע בתחילת הItem- אופציונלי.

Checkbox

במצב של Multi Selection, מאפשר בחירה של כמה אפשרויות.

Select all

במצב של Multi Selection, מאפשר סימון של כל האפשרויות -אופציונלי.

Remove all

במצב של Multi Selection, מאפשר הסרה של כל האפשרויות שנבחרו- אופציונלי.

Clear Icon

אייקון Cancel מופיע בבחירה של Filterable Dropdown, מאפשר מחיקה של הText Field שהוזן.

Heder Level 1

כותרת של אפשרות שפותחת מתחתיה עוד אפשרויות

Level 2

אפשרות בהיררכיה פנימית יותר.

Level 3

כמו ה- Level 2 רק שלב אחד פנימה בהיררכיה.

Icon

סמל שמופיע בתחילת הdropdown- אופציונלי.

Tags

הערכים הנבחרים מוצגים כתגיות הניתנות להסרה.

## מתי להשתמש (מתי להשתמש)

- כדי לחסוך מקום בממשק כאשר רשימת האפשרויות לבחירה ארוכה מידי להצגה מלאה.
- בטפסים, ב- Modals או ב- Side Panels. הרכיב משמש לסינון או מיון בדף.
- נשתמש באופציה של Single selection כאשר נדרשת בחירה של אפשרות אחת.
- נשתמש באופציה של Multi selection כאשר נדרשת בחירה של יותר מאפשרות אחת.

## מתי להימנע (מתי להימנע)

- כאשר יש רק 2 אפשרויות לבחירה ו- Radio button או Toggle מתאימים יותר.
- אם האפשרויות דורשות מידע מורכב מידי שאין לו מקום ברשימה פשוטה.
- אם פעולת בחירת אפשרות אמורה להפעיל פעולה מיידית או ניווט.
