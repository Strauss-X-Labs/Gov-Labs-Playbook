## הוראות שימוש ברכיב (הוראות בנייה (Figma))

נייבא מפאנל ה- Assets את ה- Side Bar Item.

נשכפל אותו לפי הצורך על פי מספר הדפים שנרצה לתת אפשרות לנווט אליהם ומספר הכותרות שנרצה לשים, ונייצר Auto Layout עם מרווח של 0 בין הפריטים.

במידה ונרצה להוסיף אופציית חיפוש נייבא מפאנל ה- Assets את ה- Search Field, נוסיף גם אותו ל- Auto Layout ונייצר מרווח של 16 px.

נוסיף Fill ברקע של neutral-default, וניתן Offset של 16 px מלמעלה, ומלטה עד שימלא את גובה המסך.
