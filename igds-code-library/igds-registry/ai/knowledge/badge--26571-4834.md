## סוגים (סוגים / וריאנטים)

השוני בין הסוגים מתאפיין על ידי צבעי הרקע. יש לשנות את תיאור הטקסט בהתאם לשימושים שלהם

Informative

מציג מידע אינפורמטיבי ״להגשה״/ ״נפתח להגשה״

In-progress

סטטוס ״עדיין בעבודה״ / ״בתהליך״/ ״טיוטה״/ ״בבדיקה״

Success

סטטוס ״בוצע בהצלחה״/ ״הושלם״/ ״פורסם״

Warning

סטטוס ״שימו לב״/ ״טרם נפתח״

Failure
