## (intro) (מבוא)

אייקון הוא אלמנט גרפי אשר מטרתו לתקשר באופן חזותי פעולה או מידע

להנחיות שימוש במסגרת איפיון ודוגמאות:

### מרכיבים (אנטומיה)

Graphical element

הצורה הוקטורית המרכזית המייצגת חזותית את מטרת הסמל

Container

המיכל שמגדיר את המימדים המקסימליים של הסמל ומשפיע על האזור שניתן ללחיצה

Spacing

המרווחים מסביב לסמל הפועלים לפי כלל ה8 פיקסלים כדי להבטיח הפרדה מספקת מאלמנטים אחרים

### סוגי אייקונים (סוגים / וריאנטים)

Action icons

אייקונים שמזמנים את המשתמש לבצע משימות או פעולות

Description icons

אייקונים חזותיים המבהירים ומשלימים מידע טקסטואלי

Status icons

מחוונים המציגים את מצבו הנוכחי או תנאי של מערכת או תהליך

Navigation icons

איייקונים המקלים על תנועת המשתמש בממשק

Status icons

### מתי להשתמש (מתי להשתמש)

- כאשר האייקון מייצג פעולה ברורה ומיידית (למשל: עריכה, מחיקה, הורדה).
- כתוספת ויזואלית לכפתור פעולה שמחזקת את משמעותו.
- כאשר פעולה נפוצה ומוכרת למשתמשים (אייקון "חיפוש", "פלוס", "הגדרות").

### מתי להימנע (מתי להימנע)

כאשר הפעולה אינה סטנדרטית ועלולה להתפרש במספר דרכים.
כאשר האייקון עומד לבד ללא טקסט מלווה בפעולות מורכבות.
כאשר האייקון משמש לקישוט בלבד ללא משמעות פונקציונלית.

Action icons

### מתי להשתמש (מתי להשתמש)

- להדגשת מידע ולא לשם ביצוע פעולה.
- לתמיכה בקטגוריות תוכן (למשל: מידע כללי, אזהרה, עזרה).
- לשיפור קריאות במקרים של רשימות או כותרות משנה.

### מתי להימנע (מתי להימנע)

במקום טקסט שחיוני להבנת התוכן.
כאשר האייקון עלול להתפרש בטעות כסימן לפעולה.
כאשר שימוש מרובה באייקונים פוגע בניקיון הממשק.

Description icons

### מתי להשתמש (מתי להשתמש)

- להצגת מצב בזמן אמת (למשל: הצלחה, כישלון, טעינה).
- כאשר יש צורך בהמחשה מהירה של סטטוס שאינו דורש פירוט.
- בליווי טקסט מתאים במקרים של מצבים קריטיים.

### מתי להימנע (מתי להימנע)

כאשר הסטטוס אינו חד-משמעי או דורש הסבר נוסף.
כאשר משתמשים באייקונים דומים מדי למצבי פעולה או תיאור.
בהעברת מידע קריטי ללא טקסט מלווה (לטובת נגישות).

Navigation icons

### מתי להשתמש (מתי להשתמש)

- כאשר האייקון מוביל למעבר למסך, דף או אזור חדש.
- בממשקי מובייל כדי לחסוך מקום (למשל: חזרה, תפריט, חיפוש).
- כאשר האייקון מייצג תנועה מוכרת (חצים, תפריט המבורגר).

### מתי להימנע (מתי להימנע)

- כאשר הקישור אינו ברור דיו ממשמעות האייקון.
- כאשר הניווט אינו מיידי או דורש הסבר נוסף.
- כאשר אייקון ניווט משמש בטעות כפעולה או להפך.
