## (intro) (מבוא)

לאחר שבחרתם או בחרתן את ה-Header המתאים ביותר, יש להתאים את הלוגו וה-Menu Items.

*טיפ חשוב:
אם אתם משתמשים באותו ההדר עבור דפים רבים, מומלץ להכין את ההדר מראש ולהעתיק אותו לכל המסכים במקום לעדכן כל מסך בנפרד.

דרישות הלוגו:
גודל: 120x32 פיקסלים.
בשימוש בשני לוגואים התאימו את הלוגואים לגרסת Mobile,  בגודל 32x32 פיקסלים (סמליל בלבד).
פורמט נתמך: JPG, PNG, SVG.

פורמט PNG, JPG

פורמט SVG

לחצו על ה-Header שבו תרצו לשנות את הלוגו.

יש להפוך את הלוגו לקומפוננטה.

יש לבחור בפורמט ה- SVG Placeholder בפאנל ה-Design

ב-Layers Panel ומצאו את ה-Layer שנקרא Placeholder.
נווטו ל-Layer שנקרא Replace this. לחצו עליו כדי לבחור אותו.

יש לבצע Swap ל-SVG Placeholder ולבחור את הקומפוננטה של הלוגו שיצרת.

לאחר שבחרתם את ה-Layer, גשו לחלון העיצוב (Design Panel).
בשדה ה-Fill, לחצו על שורת ה-Image.

בחלונית שנפתחה, הניחו את סמן העכבר מעל התמונה הנוכחית. לחצו על האפשרות Upload from computer ובחרו את הקובץ המתאים מהמחשב שלכם.

## מילוי שדות ה- Menu Items עבור צוות הפיתוח (הוראות בנייה (Figma))

לאחר ייבוא רכיב ה-Header מתוך פאנל ה-Assets, יש למלא את פרטי ה-Top Menu בהתאם.

יש לשכפל את ה-Header ולהציבו בסמוך לדפים הרלוונטיים בעיצוב.

בפאנל ה-Design יש להפעיל את האפשרות Open Menu’s for Dev ולמלא את השדות בהתאם להגדרות באפיון/עיצוב.

יש להשאיר את ה-Header המיועד לפיתוח קרוב לדפים הרלוונטים ולסמנם עבור צוות הפיתוח. יש לוודא שכל תפריטי ה- Dropdown מותאמים לדפים הרלוונטים
