## מתי להשתמש (מתי להשתמש)

- כדי לעזור למשתמש לנווט בתוך הממשק באמצעות שימוש במילות חיפוש.
- ברמת הדף בעת חיפוש תוכן בעמוד ספציפי או ברמת הרכיב בעת חיפוש נתונים ברכיב ספציפי, כגון טבלת נתונים.
- עדיף למקם את הרכיב בכותרות או באזור הניווט לגישה קלה.

## מתי להימנע (מתי להימנע)

- באתרים שבהם יש מעט תוכן וניתן לנווט באופן מדויק יותר באמצעות סרגל הניווט.
- יש להימנע משימוש כתחליף למבנה ניווט טוב או ארגון תוכן ברור.
- יש להימנע משימוש אם החיפוש יקשה על איתור התוכן המבוקש.

## דגשים (דגשים)

- מיקום החיפוש חשוב- אם החיפוש בהאדר הוא יהיה מקושר לחיפוש בכל האתר, אם החיפוש בראש עמוד- מקושר לחיפוש רק בעמוד הנ”ל, כנל לגבי טבלה וכדומה.
- האייקון שמופיע ב- List Item ישתנה לפי המצבים הבאים (הכוונה בתוצאות החיפוש שנפתחות):
- Search Icon - כאשר זו פעם ראשונה שמחפשים משהו
- Clock Icon - כאשר מחפשים משהו שכבר חיפשנו בעבר
- File Icon - כאשר מחפשים קובץ
- Government office Icon - כאשר מחפשים משרד ממשלתי ספציפי
- השימוש במצב Collapsed יהיה במובייל (מפאת חוסר במקום)

## עשה ואל תעשה (עשה ואל תעשה)

הימנע מהוספת מסננים רבים מדי או אפשרויות מתקדמות ישירות בשדה החיפוש. שמור על החוויה הראשונית פשוטה, עם אפשרויות מתקדמות זמינות במידת הצורך.

ודאו ששדה החיפוש ניתן לזיהוי ברור, עם סמל זכוכית מגדלת כדי לציין את תפקידו.

הציעו השלמה אוטומטית או הצעות בזמן שהמשתמשים מקלידים כדי להאיץ את תהליך החיפוש ולעזור להם למצוא את מה שהם מחפשים במהירות.

הימנע מהקפדה מדי באיות ובעיצוב. יישם סובלנות לשגיאות הקלדה או וריאציות קלות כדי לשפר את חווית החיפוש.

אודות

אל תחביאו את שדה החיפוש תחת תפריטים או רכיבי ממשק משתמש אחרים. זה צריך להיות נגיש בקלות מבלי לדרוש קליקים או פעולות נוספות.

ספק לחצן ברור (סמל 'X') בתוך השדה כדי לאפשר למשתמשים לאפס במהירות את שאילתת החיפוש שלהם.

נשתמש  כאשר אנו מתמודדים עם מערכי נתונים גדולים מאוד, חלוקת מרחב החיפוש יכולה לעזור לשפר את היעילות ולצמצם את הזמן הנדרש למציאת המידע הרצוי.

לא נשתמש כאשר שני החיפושים אינם קשורים זה לזה

כאשר למשתמשים יש קריטריונים או תנאים ספציפיים שצריך לעמוד בהם (למשל, טווח מחירים, טווח תאריכים, קטגוריה), חיפוש הסינון מאפשר להם להתמקד בתוצאות רלוונטיות התואמות את הקריטריונים הללו.

כאשר המסננים מורכבים מדי או קשים להגדרה, זה עשוי להיות מאתגר ליישם ולהשתמש בחיפוש מסננים בצורה יעילה. במקרים כאלה, שיטת חיפוש פשוטה יותר עשויה להיות עדיפה.
