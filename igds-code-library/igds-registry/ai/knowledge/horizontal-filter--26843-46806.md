## מתי להשתמש (מתי להשתמש)

- כאשר רוצים לסנן רשימות נרחבות או מידע- Large Dataset
- כאשר רוצים לצמצם תוצאות חיפוש, Search Results, ולעזור למצוא את התוצאות הרלוונטיות ביותר
- טבלאות נתונים- לאפשר להציג רק את השורות שעומדות בקריטריונים מסוימים
- כדי להתאים אישית תצוגה של מדדים או דוחות על סמך פרמטרים ספציפיים ב- Dashboard

## מתי להימנע (מתי להימנע)

- יש להימנע כאשר ניתן לראות את הרשימה המלאה ללא סינון נוסף ושימוש בסינון יוסיף מורכבות מיותרת
- כאשר יותר מידי מסננים עלולים להוביל למחסור בתוצאות (סינון יתר)
- אם סינון נתונים עלול לגרום למשתמש לפספס מידע קריטי
- בנתונים בזמן אמת, שמשתנים כל הזמן, ומסננים עלולים להתיישן במהירות
- כאשר יש סבירות גבוהה שהמשתמש יזדקק לבחור באפשרות בודדת, יש לשקול להשתמש ברכיב אחר, לדוגמה: Switch

## עשה ואל תעשה (עשה ואל תעשה)

במידה ורוצים להראות פחות מ-5 Dropdown, יש למחוק ידנית עד למספר הרצוי וה-Dropdown הנותרים ימלאו את רוחב הContainer
בשימוש ב- Filter עם שתי שורות, במידה ורוצים להוריד בכמות ה- Dropdown, נשים לב לשמור על אותו רוחב של הDropdown בשורה למעלה עם הפונקציה FIx על הרוחב.

אין לפתוח את הDropdown בתוך הFilter עצמו. עבור הפיתוח יש להראות בצד את המצב הפתוח.
