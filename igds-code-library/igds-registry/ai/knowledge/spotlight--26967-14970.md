**רכיב Overlay שמדגיש ומסביר אלמנט מסוים במסך, מספק הדרכה במהלך תהליך Onboarding, מציג פיצ’רים חדשים, ומסייע למשתמשים בביצוע משימות מורכבות.**

## סוגים (סוגים / וריאנטים)

Multiple Step’s

חוויית הדרכה המובילה את המשתמש דרך מספר אלמנטים או פעולות.  מומלץ להגביל את מספר השלבים ל-3–4 לכל היותר.

Single Announcement

הודעה חד-פעמית המסבירה פיצ’ר חדש או שינוי במערכת, ללא שלבי ניווט.

*לחיצה מחוץ ל-Spotlight תסגור אותו ותאפשר המשך עבודה.

## דגשים לשימוש (דגשים)

Spotlighted Element

יש להוסיף מסגרת בעובי 4px סביב האלמנט המודגש, בצבע שנקרא spotlighted element וצל ברמת Level- 1. המסגרת נועדה להקל על זיהוי האלמנט אליו מתייחס ה-Spotlight, ולחזק את הקשר בין ההנחיה לתוכן שעל המסך.

## מתי להשתמש (מתי להשתמש)

- להדרכת משתמשים חדשים והכוונתם דרך רכיבים מרכזיים בממשק, במהלך הביקור הראשון.
- להצגת פיצ’רים חדשים או שינויים משמעותיים, תוך הדגשה והסבר שלהם.
- להכוונה במשימות מורכבות, כאשר הפעולה אינה אינטואיטיבית או כוללת ריבוי צעדים.

## מתי להימנע (מתי להימנע)

- כאשר ההסברים פשוטים. Tooltip בסיסי מספיק, גם בממשק חדש.
- כאשר השימוש תכוף. שימוש חוזר ונשנה עלול לעייף את המשתמש ולהיתפס כמציק.
- במהלך תהליכים חשובים או רגישים בזמן (כגון תשלום או שליחת טופס).
- כאשר האלמנטים אינם ניתנים למיקוד – יש להימנע מהדגשה של אלמנטים שלא ניתן להבליט או ליצור איתם אינטראקציה.
