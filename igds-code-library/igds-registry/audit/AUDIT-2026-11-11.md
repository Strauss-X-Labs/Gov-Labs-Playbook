## 2. האם 73 הוא המספר המלא?

**כן — עבור Web Components ב־`@igds/core-web` 0.1.59.** ארבע שיטות בלתי־תלויות מסכימות:

| שיטה | תוצאה |
|---|---|
| `IGDS_TAGS` enum ב־`constants/tags.d.ts` | 73 |
| חילוץ TypeScript (`build-registry.mjs`) | 73 |
| **יירוט כל `customElements.define`** בזמן טעינת ה־bundle הרשמי ב־Edge (חדש, `evidence/code-runtime-defines.txt`) | 73 `igds-*`, 0 אחרים בזמן טעינה |
| `verify-runtime.mjs` — `customElements.get` לכל תג | 73/73 |

אין תג `igds-*` שמוגדר ואינו ברשימה, ואין תג ברשימה שלא מוגדר. 137 המחרוזות `igds-*` ב־bundle הן 73 תגים + שמות אירועים ומחלקות CSS.

**אבל 73 אינו "כל ספריית הקוד":**
- **73 = רכיבים + תתי־רכיבים.** 30 מתוך ה־73 אין להם component set ציבורי ב־Figma, ורובם תתי־רכיבים שמופיעים רק בתוך הורה (`igds-step-item`, `igds-tab-panel`, `igds-table-cell`, `igds-toolbar-item`…). לא בוצעה ספירה פורמלית של "עצמאי מול תת־רכיב".
- **414 אייקונים ב־`@igds/icons` — 0 מהם ב־Registry.** ה־lint לא מוודא שם אייקון.
- **עטיפות Framework** (`@igds/react`, `@igds/angular`) — לא נבדקו (חסר טוקן). אם קיימות, ה־API שלהן (`onIgdsChange` וכו') לא מכוסה בכלל.

### איך הבדיקות מזהות רכיב שהוחמץ לגמרי
- **Figma:** ה־inventory (ספירה לפי עמוד, `findAllWithCriteria`) מושווה לכל לכידה מפורטת לפי עמוד → `missedByCapture`. היום: 0 בעמודי Web; עמודי Icons/Atoms מסומנים "שמות בלבד".
  ספירה בשיטה שנייה (XML של `get_metadata`) נבדקה רק על עמוד Button. **הרחבה לכל העמודים — עוד לא בוצעה.**
- **קוד:** enum ↔ TS ↔ יירוט `define` בזמן ריצה ↔ `customElements.get`. כל תג שיתווסף לספרייה ולא ייקלט — ייכשל.

**אין כאן 100%:** הכיסוי המלא הוא רק עבור Custom Elements בקוד. Figma: 243/707 sets חולצו לעומק (34%), מתוכם 126 מופו לקוד; 0% מההנחיות, ה־patterns וערכי הטוקנים/סגנונות.
