# DS-Component-figma-sketch

סקיל ליצירת **סקיצת HTML עצמאית** של רכיב בודד מהדיזיין סיסטם, הנבנית מתוך
נתוני Figma (דרך **Figma MCP** + **Figma skills**) וממופה כולה לטוקנים הקיימים.
הפלט מציג את הרכיב בכל המצבים/הוריאנטים שלו — לצורך בחינה ויזואלית מהירה.

## מקורות אמת (אל תכפיל — הפנה)

הסקיל הזה **אינו מגדיר מחדש** חוקי עיצוב, טוקנים, מצבי רכיב או נגישות.
בכל שלב הישען על הקבצים הקיימים:

- **כללי עיצוב מחייבים** → `.kiro/steering/design-system.md`
- **זרימת עבודה עיצוב/אפיון/פרוטוטייפ** → `.kiro/steering/design-workflow.md`
- **מקור אמת לדיזיין סיסטם** → `design.md`
- **טוקנים ממומשים (CSS Custom Properties)** → `styles.css` (`:root`)
- **תיעוד רכיב ספציפי** → קובץ ה-MD של הרכיב בשורש הפרויקט
  (`floating-button.md`, `spin-box.md`, `step-indicator.md`, וכל קובץ רכיב נוסף)

בכל התנגשות — כללי ה-steering המחייבים גוברים.

## מתי להפעיל

כשמעצב מבקש לייצר סקיצה / mockup / תצוגת HTML של רכיב מהדיזיין סיסטם,
במיוחד כשרוצים לראות את **כל המצבים/הוריאנטים** של הרכיב במקום אחד.

## קלט נדרש מהמעצב

1. **קישור ל-frame/node בפיגמה** של הרכיב (URL עם `node-id`). חובה.
2. **שם הרכיב** ואילו מצבים/variants לכלול (או "כל המצבים").

אם חסר קישור פיגמה או חסר תיעוד רכיב — **עצור ובקש קישור ל-node**.
אל תנחש מראה, מידות או התנהגות (ראה `design-workflow.md` → "כשחסר מידע על רכיב").

## תהליך העבודה

### 1. טען הקשר Figma
טען את הנחיות Figma skills הרלוונטיות (`figma-design-to-code`) לפני משיכת context,
כנדרש בתיאור כלי ה-Figma MCP.

### 2. משוך את הרכיב מהפיגמה (Figma MCP)
חלץ `fileKey` ו-`nodeId` מהקישור, ואז:

- `get_metadata` — מפה את עץ הנוד וזהה את כל ה-variants / states (לרוב component set).
- `get_design_context` — קוד ייחוס + screenshot לכל מצב.
- `get_screenshot` — תצוגה ויזואלית להשוואה מול הפלט.
- `get_variable_defs` — הטוקנים (צבע/מרווח/טיפוגרפיה/radius) של הנוד. זה בסיס המיפוי.

### 3. מפה כל ערך לטוקן
- כל ערך גולמי מהפיגמה → **הטוקן הקרוב ביותר** ב-`styles.css`
  (`--igds-*`, `--color-*`, `--space-*`, `--font-size-*`, `--border-radius`...).
- **אסור** להצמיד ערך גולמי (hex/px) בקוד — תמיד `var(--token)`.
- **אין טוקן מתאים?** עצור ודווח על הפער. אל תמציא טוקן ואל תעתיק ערך בשקט.
  (פירוט מלא: `design-system.md` → "שימוש בטוקנים", `design-workflow.md` → "עבודה מול Figma".)

### 4. בחר רכיבים קיימים
השתמש במחלקות הקיימות (`.gov-*`, `.form-page` וכו') ו-`styles.css`.
הרחב רכיב קיים לפני יצירת חדש (ראה `design-system.md` → "רכיבים").

## פורמט הפלט — מבנה ספריית הרכיבים

כל הסקיצות חיות תחת תיקיית `sketches/` ומרכיבות ספריית רכיבים אחת למעצבים:

```
sketches/
├── index.html        ← עמוד שער (גלריה) — קישור לכל רכיב
├── _gallery.css      ← סטייל מעטפת משותף (grid, תוויות מצב, טבלת מיפוי, כרטיסים)
├── input-field.html  ← קובץ רכיב (קובץ אחד לכל רכיב)
└── <component>.html  ← רכיבים נוספים
```

כללי המבנה:

- **קובץ אחד לכל רכיב**: `sketches/<component>.html` (שם kebab-case, בלי סיומת `-sketch`).
- **לעולם אל תשכפל סטייל**. כל קובץ טוען שני גיליונות בלבד:
  - `<link rel="stylesheet" href="../styles.css">` — מקור האמת (טוקנים + מחלקות `.gov-*`).
  - `<link rel="stylesheet" href="_gallery.css">` — סטייל מעטפת הגלריה המשותף.
  - **אין** `<style>` מוטבע עם ערכי עיצוב. מחלקת תצוגה חדשה שחסרה למעטפת → הוסף ל-`_gallery.css`, לא לקובץ הרכיב.

כל קובץ רכיב כולל:

1. `<!DOCTYPE html>` עם `dir="rtl"` ו-`lang="he"`.
2. קישור חזרה לעמוד השער: `<a class="sketch__back" href="index.html">← חזרה לספריית הרכיבים</a>`.
3. **כל מצב/וריאנט בבלוק נפרד עם תווית** (`.sketch__state-label`) — לפי מה שהוחזר מהפיגמה וקובץ הרכיב.
4. נגישות ו-RTL לכל מצב — לפי `design-system.md` → "RTL ונגישות" (focus גלוי, `aria-invalid`, `role="alert"`, `aria-required`, labels, סדר Tab).
5. **טבלת מיפוי** בתחתית (`.sketch__mapping`): `ערך פיגמה → טוקן ב-styles.css → סטטוס (נמצא / פער)`.

### עדכון עמוד השער (חובה בכל רכיב חדש)

אחרי יצירת קובץ רכיב, הוסף לו כרטיס ב-`sketches/index.html` בתוך `<ul class="gallery-cards">`:

```html
<li>
    <a class="gallery-card" href="<component>.html">
        <span class="gallery-card__name">שם הרכיב</span>
        <span class="gallery-card__desc">תיאור קצר + רשימת המצבים</span>
    </a>
</li>
```

## כללי עצירה

- אין קישור פיגמה → בקש אותו.
- ערך פיגמה בלי טוקן תואם → דווח כ"פער", אל תמציא.
- רכיב לא מתועד ואין frame → בקש frame, אל תנחש.
