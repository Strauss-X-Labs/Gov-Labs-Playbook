Horizontal Filter — רכיב פילטור

מיפוי טוקנים (Figma → styles.css)

הפילטר הוא קומפוזיציה של רכיבים קיימים, לכן אין ערכי מראה חדשים — רק מרווחי פריסה. המראה של כל Dropdown / Checkbox / Button מגיע מהטוקנים של הרכיב הקיים (ראו הסקיצות שלהם). הטבלה למטה מכסה את מרווחי הפריסה של הפילטר עצמו.
