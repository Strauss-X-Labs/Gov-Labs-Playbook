מבנה (HTML)

הרכיב עוטף button.gov-notification-button__btn (האייקון) יחד עם .gov-numeric-badge הקיים כתגית צפה (.gov-notification-button__badge). התגית ממוקמת בפינה המובילה (שמאל ב-RTL). האייקון aria-hidden, הכפתור נושא aria-label המתאר את הפעולה ומספר ההתראות. המצבים (Hover/Pressed/Focused/Disabled) זהים לרכיב Button לכל סוג.
