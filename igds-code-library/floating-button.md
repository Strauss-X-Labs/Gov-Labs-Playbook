# Floating Action Button (FAB)

## Introduction

כפתור ראשי צף הממוקם בשכבה העליונה של העמוד ונמצא במצב סטיקי — תמיד רואים אותו.
הכפתור משמש להדגשת הפעולה החשובה ביותר על המסך, ומספק גישה מהירה ונוחה לפעולות מפתח.

---

## Anatomy (אנטומיה)

הכפתור הצף מורכב משלושה חלקים:

| # | Element | תיאור |
|---|---------|--------|
| ① | **Container** | האזור שמכיל את ה-Label והאייקון ומגדיר את גודל וצורת הכפתור |
| ② | **Icon** | מלווה את הטקסט בכפתור או מתאר את הפעולה בכפתור עם אייקון בלבד |
| ③ | **Label** | הטקסט בתוך הכפתור שמתקשר את הפעולה למשתמש |

### וריאנטים

- **אייקון בלבד** — עיגול עם אייקון (מצב מכווץ)
- **אייקון + טקסט** — כפתור מורחב עם אייקון ו-label (מצב מורחב)
- **טקסט בלבד** — כפתור מורחב עם label בלבד

## Use Cases (שימושים)

הכפתור הצף יכול לשמש עבור:

- **Back to Top** — חזרה לראש העמוד
- **Chat** — פתיחת צ'אט תמיכה
- **Add New** — הוספת פריט חדש (טופס, הודעה וכו׳)

> לכל שימוש יהיה אנימציה שונה בהתאם לפעולה שהוא מייצג.

---

## When to Use (מתי להשתמש) ✅

- כדי להדגיש את הפעולה החשובה ביותר על מסך
- כאשר פעולה ראשית יחידה צריכה להיות נגישה בקלות
- ביישומים שבהם המקום מוגבל, אך פעולת מפתח צריכה להתבלט
- כדי לספק גישה מהירה לתכונות בשימוש תכוף, כגון הוספת פריט חדש או כתיבת הודעה

---

## When Not to Use (מתי לא להשתמש) ❌

- כאשר יש להציג מספר פעולות ראשוניות באופן שווה
- בהקשרים שבהם כפתור צף עשוי לטשטש תוכן חשוב
- במסכים שבהם הפעולה העיקרית כבר מסומנת בבירור ונגישה בקלות דרך רכיבי ממשק משתמש אחרים
- במצבים בהם השימוש בכפתור צף עלול לגרום לבלבול או לשבש את זרימת המשתמש

---

## Accessibility (נגישות והנגשה לאוכלוסיות קצה)

- בכפתורים המיועדים לאוכלוסיות קצה, כגון משתמשים עם אוריינות דיגיטלית נמוכה — **מומלץ לשלב טקסט לצד האייקון** ולא להסתמך על האייקון בלבד כמייצג את הפעולה
- יש להשתמש ב**שפה מדוברת, ישירה ובלתי-פורמלית** ככל הניתן, תוך הימנעות ממונחים מקצועיים או טכנולוגיים
- יש להשתמש ב**טקסט ברור ומפורש** — לדוגמה: "שליחת הבקשה" במקום "שלח"
- הטקסט על הכפתור צריך להיות **תיאורי** — "שלח טופס", לא "הבא"

---

## Placement (מיקום על המסך)

- ניתן להשתמש במספר סוגי כפתורים כדי לבטא רמות דגש שונות
- בסרגל תחתון, בעת שימוש במספר כפתורים — ציין את הפעולה החשובה יותר על ידי הצבתה בכפתור כלול ליד כפתור טקסט או כפתור משני
- **לעולם אל תשתמש בשני כפתורים ראשיים זה ליד זה** — כך תבלבל את המשתמש עם ההיררכיה
- **חריג:** שימוש ב-Primary Button רגיל יחד עם כפתור צף באותו מסך — זה מותר

---

## Do's and Don'ts

### ✅ Do

- ניתן לשים 2 כפתורים צפים אחד מעל השני (למשל: כפתור צ׳אט + כפתור חזרה למעלה) — אחד Primary והשני Secondary
- שלב טקסט עם אייקון כדי לשפר הבנה

### ❌ Don't

- **אין** לשים 2 כפתורים ראשיים (Primary) אחד ליד השני
- **אין** להוסיף Badge לכפתור צף
- **אין** לשים אייקונים לא ברורים ללא טקסט
- **אין** להשתמש בכפתור מרחף (מצב מורחב) עם אייקון בלבד
- **אין** להשתמש ברכיב ככפתור מרחף לרכיבים אינדיבידואלים (כגון כרטיסים שלכל אחד יש כפתור צף משלו)

## Design Tokens Summary

```css
/* Primary FAB */
--fab-bg-primary: #0068F5;          /* button/background-primary */
--fab-text-primary: #F5F9FF;        /* button/text-primary */

/* Secondary FAB */
--fab-bg-secondary: #FFFFFF;        /* background/neutral-default */
--fab-border-secondary: #0068F5;    /* button/border-primary */
--fab-text-secondary: #0068F5;      /* button/text-secondary */

/* Shared */
--fab-shadow: shadow-dark/level3;
--fab-size-desktop: 60px;
--fab-size-mobile: 48px;
--fab-border-radius: 50%;           /* icon only */
--fab-border-radius-expanded: 999px; /* with label */
```
