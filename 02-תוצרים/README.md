# 02 — תוצרים

תוצר = ישות עצמאית. **קובץ אחד לתוצר**, שעונה על: מה זה, איך זה בנוי, איך מייצרים אותו, ואיך AI עוזר.
תוצר משויך ליום דרך לינק מ-[01-ימים](../01-ימים/), אבל עומד בפני עצמו.

ב-repo של מיזם יש תיקיית `תוצרים/` עם **אותם שמות** — שם הקבוצה ממלאת את התוצר בפועל.

## מועמדים — לאישור

תוצרים שמופיעים ב[מודל התלת-צירי](../00-התוכנית/המסע.md) ועדיין אין להם קובץ. לפתוח קובץ רק אחרי שהצוות מאשר שזה תוצר נפרד ולא חלק מקיים:

| מועמד | ציר | אולי חלק מ- |
|---|---|---|
| בעלי-עניין (מפת stakeholders) | עסקי | חקר-הבעיה |
| מודל-כלכלי | עסקי | Lean-Canvas |
| מדדי-ROI | עסקי | Lean-Canvas / Investment-Deck |
| מסע-משתמש | מוצר | פרסונה / עיצוב-מוצר |
| User-Testing | מוצר | עיצוב-מוצר |
| Spec | פיתוח | ארכיטקטורה / Product-Backlog |

תוצר חדש? העתק את [_תבנית.md](_תבנית.md).
