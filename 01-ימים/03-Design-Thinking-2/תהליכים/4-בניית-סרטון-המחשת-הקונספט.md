**הפלטה (החלטה 5), כפי שהוגדרה:**

```css
:root{
  --gov-blue:#0068F5;       /* הכפתור הראשי, קו הדגשה מתחת לכותרת */
  --gov-blue-dark:#0045A3;  /* קישורים וטקסט כחול, hover של הכפתור, כותרת משנה */
  --gov-blue-bg:#E9F4FF;    /* רקע לאזור מודגש או לכרטיס */
  --gov-blue-tint:#B7D6FF;  /* גבולות, פס התקדמות ריק */
  --gov-ink:#333333;        /* טקסט */
  --gov-gray:#707070;       /* טקסט משני, גילוי נאות */
  --gov-gray-bg:#F2F2F2;    /* רקע הדף מחוץ לתוכן, מפרידים */
  --gov-white:#FFFFFF;      /* רקע התוכן */
  --gov-font:"Assistant","Rubik","Arial Hebrew",Arial,sans-serif;
}
```

גופן Assistant מ-Google Fonts (`https://fonts.googleapis.com/css2?family=Assistant:wght@400;600;700&display=swap`), המשאב החיצוני היחיד שהותר. גובה שורה 1.6. כפתור ראשי `--gov-blue` עם טקסט לבן במשקל 600, ב-hover `--gov-blue-dark`. קישורים וטקסט כחול קטן רק ב-`--gov-blue-dark` (ניגודיות). פינות עד 8 פיקסלים, בלי צללים כבדים ובלי גרדיאנטים.
