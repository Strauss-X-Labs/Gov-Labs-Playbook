## א. מטרת התהליך

בעידן של AI-SDLC ו-Vibe Coding, המודל הישן — "אפיון ➔ העברה לסטודיו עיצוב ➔ שבועיים המתנה ➔ העברה למפתחים ➔ שבועיים פיתוח" — הוא **כשל מערכתי שמונע חדשנות.**

**הפרדיגמה החדשה: יום אחד, צוות אחד, מוצר עובד.** באמצעות כלי יצירה מודרניים (Figma Make, Cursor, Claude Code, v0), הצוות יחד עם ה-End-to-End Product Lead מייצרים בתוך **4 שעות עבודה מעבדתית 50% מקוד הפרונטנד** של המוצר — מחובר ל-Design System אמיתי, רספונסיבי, ופועל עם Mock Data אינטראקטיבי.

## ב. עקרונות מנחים

- **Product, לא Prototype.** אפליקציית Web אינטראקטיבית שאפשר להקליד בה — לא "תמונה סטטית".
- **Design System ממשלתי, לא עיצוב מאפס.** הרכיבים כבר קיימים; הסדנה מרכיבה.
- **הצוות סביב המסך.** בדיקה חיה, זיהוי חיכוך, ושינוי הקוד בזמן אמת בשיח מול הסוכן.
- **ה-MD הוא הקלט.** מפרט ה-MVP ומטריצת הרכיבים נטענים לסביבה — [Spec-Driven](../../../03-ידע/מתודות/Spec-Driven-Development.md) בפועל.

## סביבת הפיתוח והכלים (Tools & Agent Setup)

## ג. זרימת התהליך

### שלב א׳: הזנת ה-Context וה-Design System לסביבת ה-Vibe Coding (20 דקות)
ה-Product Lead טוען לסביבת העבודה (Cursor / v0) את קבצי ה-MD של המיזם:
- [מפרט MVP](../../../02-תוצרים-וטמפלטים/מפרט-MVP.md) — מפרט ה-Core Loop.
- [דף ערכי מוצר](../../../02-תוצרים-וטמפלטים/דף-ערכי-מוצר.md) — מטריצת הרכיבים.
- הנחיות ה-Design System הממשלתי: צבעים, טיפוגרפיה, רכיבי כפתורים ושדות.

### שלב ב׳: ייצור מסך הכניסה ולולאת הפעולה הראשית — Vibe Iteration 1 (60 דקות)
- הפקת שלד המסכים הראשון באמצעות הנחיות שפה טבעית מובנות (Prompt-to-UI).
- הצוות יושב סביב המסך: בדיקה חיה, זיהוי חיכוך, ושינוי הקוד בזמן אמת בשיח מול הסוכן — *"קצר את המרחק בין הכפתור להסבר, הפוך את העלאת הקובץ ל-Drag and Drop ענק, ושקף את ערך השקט הנפשי."*

### שלב ג׳: הזרקת Mock Data וחיבור שכבת ה-AI המדומה (45 דקות)
- הסוכן מייצר נתוני הדמיה מציאותיים לחלוטין: תעודות זהות מדומות, קבצי PDF לדוגמה, תשובות סוכן אנליטיקה.
- חיבור הנתונים לרכיבי הממשק — כך שהאב-טיפוס אינו "תמונה סטטית" אלא **אפליקציית Web אינטראקטיבית מלאה** שניתן להקליד בה ולקבל תגובות מיידיות.

### שלב ד׳: סבב ליטוש חווייתי — Design Polish Loop (40 דקות)
- התאמה לרזולוציית מובייל ודסקטופ.
- וידוא עמידה בעקרונות **נגישות ממשלתיים (רמת AA)**.

### שלב ה׳: בדיקת מעבר חיה — Click-Through Dry Run (15 דקות)
חבר צוות מדגים את המסלול המלא (**Golden Path**) על גבי המסך הגדול — ללא תקלות.
