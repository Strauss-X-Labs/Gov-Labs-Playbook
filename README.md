# Gov-Labs Playbook

המוח של תוכנית Gov-Labs 2.0 — מקור אחד, בפורמט Markdown, לכל מה שמנטור צריך כדי להוביל קבוצה.

| תיקייה | מה יש שם |
|---|---|

| [01-ימים](01-ימים/) | יום = אינדקס דק: מטרה, סדר יום, לינקים לתוצרים |
| [02-תוצרים](02-תוצרים/) | תוצר = ישות עצמאית. קובץ אחד לתוצר: מה זה, מבנה, איך מייצרים, AI |
| [03-ידע](03-ידע/) | ידע כללי שלא קשור ליום ספציפי — מתודולוגיות וסטנדרטים |

## שני repos, לא אחד

- **repo זה** — המוח של התוכנית. מתוחזק על ידי שטראוס אסטרטגיה.
- **repo לכל מיזם** — נוצר מ-[תבנית-מיזם](תבנית-מיזם/). הקבוצה עובדת רק בו. הסוכן של המנטור רואה את שניהם.

## איך תורמים

קרא את [איך-תורמים.md](איך-תורמים.md). עובד עם סוכן? [פרומפט-שילוב-תוכן.md](פרומפט-שילוב-תוכן.md). בקצרה: אם אתה יודע איפה זה שייך — שים שם. אם לא — `_תיבת-כניסה/`. העיקר שהחומר ייכנס.
