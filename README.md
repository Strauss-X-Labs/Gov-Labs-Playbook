# Gov-Labs Playbook

ספר המהלכים הרשמי של תוכנית Gov-Labs 2.0 — המאיץ הדיגיטלי הממשלתי בעידן הבינה המלאכותית. מאגד את מודל ההפעלה, המתודות, ימי התוכנית, התהליכים, התוצרים והטמפלטים, לצד סוכני AI כשותפים ומנטורים נוספים לצוותים.

**תשתית חיה.** כל שינוי במתודולוגיה או בכלים מתעדכן פעם אחת בקובץ ה-Markdown הרלוונטי ומחלחל לכלל רשת הסוכנים והמשתתפים. מתחילים ב-[00-התוכנית](00-התוכנית/).

**מנטור?** → **[המדריך למנטור לעבודה עם ה-Playbook](https://claude.ai/artifact/TDTCr53RVNnHw4VhX5XCfg)** — הכנת סביבת העבודה, הקמת מיזם, ועבודה שוטפת עם הצוות והסוכנים. המקור: [מדריך-למנטור.html](מדריך-למנטור.html).

**משתתף?** → **[המדריך למשתתף ב-Gov-Labs](https://claude.ai/artifact/CDBAVWZZk2kdDNsAYnCA61)** — מה זו התוכנית, איך עובדים עם AI, ומה קורה בכל מפגש. המקור: [05-משתתפים/מדריך-למשתתף.html](05-משתתפים/מדריך-למשתתף.html).

## שני repos, לא אחד

- **repo זה** — המוח של התוכנית. מתוחזק על ידי שטראוס אסטרטגיה.
- **repo לכל מיזם** — נוצר מ-[תבנית-מיזם](תבנית-מיזם/). הקבוצה עובדת רק בו: החומר הגולמי ב-`01-ימים/`, התוצרים ב-`תוצרים/`. עותק של ה-repo הזה נכנס אליו ב-`.playbook/`, כך שהסוכן רואה את שניהם מתוך ה-repo של המיזם.
