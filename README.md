# Gov-Labs Playbook

ספר המהלכים הרשמי של תוכנית Gov-Labs 2.0 — המאיץ הדיגיטלי הממשלתי בעידן הבינה המלאכותית. מאגד את מודל ההפעלה, המתודות, ימי התוכנית, התהליכים, התוצרים והטמפלטים, לצד סוכני AI כשותפים ומנטורים נוספים לצוותים.

**תשתית חיה.** כל שינוי במתודולוגיה או בכלים מתעדכן פעם אחת בקובץ ה-Markdown הרלוונטי ומחלחל לכלל רשת הסוכנים והמשתתפים. מתחילים ב-[00-התוכנית](00-התוכנית/).

## שני repos, לא אחד

- **repo זה** — המוח של התוכנית. מתוחזק על ידי שטראוס אסטרטגיה.
- **repo לכל מיזם** — נוצר מ-[תבנית-מיזם](תבנית-מיזם/). הקבוצה עובדת רק בו. הסוכן של המנטור רואה את שניהם.

## איך תורמים

קרא את [איך-תורמים.md](איך-תורמים.md) — כולל הפרומפט לעבודה עם סוכן. בקצרה: אם אתה יודע איפה זה שייך — שים שם. אם לא — `חומרי-מקור/לא-ממוין/`. העיקר שהחומר ייכנס.
